## 🌌 Overview

Welcome to the repository of **Priyank Khatri's Developer Portfolio**. Designed from the ground up to break away from traditional static templates, this application is a **high-fidelity, studio-grade digital showcase** built to demonstrate full-stack engineering proficiency, spatial UI/UX design, micro-interactions, and high-performance WebGL graphics.

### 🌟 Core Design Philosophy
- **Ethereal Cyber Aesthetic:** Deep monochromatic darkness enriched with subtle silver gradients, ambient particle fields, and sleek glassmorphism.
- **Organic Motion Physics:** Zero layout jarring. Fluid route transitions, spring physics, and Lenis smooth scrolling.
- **Autonomous AI Assistant:** Built-in portfolio chatbot dynamically responding to recruiter inquiries using an integrated semantic knowledge graph.
- **ATS-Optimized Printable Engine:** High-contrast, single-page monochrome HTML and vector PDF resume synchronized directly with portfolio records.

## 🚀 Key Feature Matrix

| Feature | Tech / Engine | Description |
| :--- | :--- | :--- |
| **🌌 3D Particle Canvas** | `Three.js` + `@react-three/fiber` | Morphing 3D particle cloud responding in real-time to scroll velocity, mouse vectors, and active routes. |
| **⚡ Smooth Navigation** | `React Router v7` + `Framer Motion 12` | Code-split lazy routes with spring physics and seamless page transitions. |
| **🤖 AI Recruiter Chatbot** | `Zustand` + `API Endpoint` | Custom AI assistant modal that answers questions about skills, projects, and background. |
| **🏆 Cinematic Credentials** | Split-Panel Showcase + PDF Modal | Interactive certificate stack with direct verification links (Meta, Hacksagon, Elite Hack, DA-IICT, Inspiron 5.O). |
| **💼 Filterable Work Route** | Dynamic Category Engine | Categorized filter (`ALL`, `SAAS`, `FULL-STACK`, `FRONTEND`, `EXPERIMENTAL`) with detailed case study views. |
| **📄 Single-Page ATS Resume** | Custom HTML Engine + Headless Chrome | Pixel-perfect A4 monochrome resume with live links and zero wasted whitespace. |

## 📂 Project Architecture

```graphql
My-Portfolio/
├── api/                    # Serverless API routes (AI chat assistant, edge functions)
├── public/                 # Static assets, certificate PDFs, ATS resume
│   ├── Priyank_Resume.pdf  # ATS-optimized single-page monochrome vector PDF
│   ├── resume.html         # High-resolution printable HTML resume engine
│   └── ...                 # Certificate PDFs & hackathon verification docs
├── src/
│   ├── components/         # Reusable modular UI components
│   │   ├── about/          # Identity panels, philosophy & storytelling blocks
│   │   ├── credentials/    # Certificate stack, details panel & progress indicator
│   │   ├── footer/         # Floating CTA & experiential footer components
│   │   ├── navbar/         # Blur-glass adaptive navigation bar
│   │   ├── work/           # Project grids, accordions, and detail views
│   │   ├── AiChatPanel.jsx # AI recruiter dialogue modal
│   │   ├── HeroBackground.jsx # 3D Three.js particle canvas
│   │   └── RootLayout.jsx  # Top-level shell with custom cursor & transitions
│   ├── data/               # Centralized single-source-of-truth data models
│   │   ├── certificatesData.js
│   │   ├── portfolioData.js
│   │   └── projectsData.js
│   ├── pages/              # Route pages (Home, About, Work, Credentials, Links, Contact)
│   ├── sections/           # Large page sections (Hero, About, TechStack, Contact)
│   ├── store/              # Zustand global state store
│   ├── App.jsx             # React Router v7 code-splitting configuration
│   ├── index.css           # Vanilla CSS tokens, typography & animation keyframes
│   └── main.jsx            # React root mount
└── vite.config.js          # Vite build & bundler configuration
```
